# AG-UI mark

The geometric mark in `../components/SiteTitle.astro` and `../../public/favicon.svg`
is adapted from the [AG-UI documentation logo](https://docs.ag-ui.com/concepts/subagents).
Source: [ag-ui-light.svg](https://mintcdn.com/tawkitai/2TrL7P1RsYhkJ7Hv/logo/ag-ui-light.svg), retrieved 2026-09-13.

The header uses the mark in the current theme's text color; the favicon uses Rust orange.
The original wordmark is replaced with an AG-UI label and a separate Rust SDK badge.
AG-UI branding belongs to its respective owners. This is an independent Rust SDK.
