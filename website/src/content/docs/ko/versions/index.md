애플리케이션의 `Cargo.lock`에 기록된 버전에 맞는 문서를 선택하세요. 헤더의
드롭다운에서 버전을 바꾸면 현재 보고 있는 페이지에 그대로 머무릅니다.

## 0.5.0-alpha.3 · 현재 프리릴리스

AG-UI 1.0과 A2UI 스트리밍 수정, renderer 메시지 검증, 폼 snapshot을 다룹니다.
A2UI의 AG-UI adapter는 이제 feature로 명시적으로 활성화합니다.
[alpha.3 가이드](/ag-ui-rust/ko/v0.5.0-alpha.3/start/)와
[마이그레이션 노트](https://github.com/KimSoungRyoul/ag-ui-rust/blob/main/docs/migration-0.5.md)를 보세요.

## 0.5.0-alpha.2 · 이전 프리릴리스

AG-UI 1.0 이벤트, 구조화된 도구 결과, 새 run 결과와 Rust 1.85 의존성 수정을 포함합니다.
[alpha.2 가이드](/ag-ui-rust/ko/v0.5.0-alpha.2/start/)는 해당 릴리스의 A2UI API와
기본 feature를 보존합니다.

## 0.4.5 · 안정 버전

기존 대화·A2UI API를 설명합니다. [0.4.5 가이드](/ag-ui-rust/ko/v0.4.5/start/)는
[`v0.4.5` 태그](https://github.com/KimSoungRyoul/ag-ui-rust/tree/v0.4.5/website/src/content/docs)의
문서를 보존했습니다.

## 0.5.0-alpha.1 · 교체됨

초기 0.5 후보 버전은 새 Rust 1.85 의존성 해석 시 빌드에 실패할 수 있습니다.
새 프로젝트에는 alpha.3을 사용하세요. 기존 pin을 위한
[alpha.1 가이드](/ag-ui-rust/ko/v0.5.0-alpha.1/start/)는 유지합니다.
