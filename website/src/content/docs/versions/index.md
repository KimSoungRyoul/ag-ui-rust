Choose the guide that matches your `Cargo.lock`. You can switch versions from
the dropdown in the header while staying on the same page.

## 0.5.0-alpha.3 · current prerelease

AG-UI 1.0 plus A2UI streaming corrections, renderer validation, and form
snapshots. A2UI's AG-UI adapter is now an explicit feature.
[Open the alpha.3 guide](/ag-ui-rust/v0.5.0-alpha.3/start/) or read the
[migration notes](https://github.com/KimSoungRyoul/ag-ui-rust/blob/main/docs/migration-0.5.md).

## 0.5.0-alpha.2 · previous prerelease

AG-UI 1.0 events, structured tool results, and new run outcomes, with the Rust
1.85 dependency fix. The [alpha.2 guide](/ag-ui-rust/v0.5.0-alpha.2/start/) preserves
that release's A2UI APIs and default features.

## 0.4.5 · stable

The previous conversation and A2UI APIs. [Open the 0.4.5 guide](/ag-ui-rust/v0.4.5/start/).
These pages are frozen from the [`v0.4.5` tag](https://github.com/KimSoungRyoul/ag-ui-rust/tree/v0.4.5/website/src/content/docs).

## 0.5.0-alpha.1 · superseded

The initial 0.5 candidate can fail with fresh Rust 1.85 dependency resolution.
Use alpha.3 for new projects. The [alpha.1 guide](/ag-ui-rust/v0.5.0-alpha.1/start/)
remains available for existing pins.
