Choose the guide that matches your `Cargo.lock`. You can switch versions from
the dropdown in the header while staying on the same page.

## 0.5.0-alpha.2 · current prerelease

AG-UI 1.0 events, structured tool results, and new run outcomes.
[Open the alpha.2 guide](/ag-ui-rust/v0.5.0-alpha.2/start/) or read the
[migration notes](https://github.com/KimSoungRyoul/ag-ui-rust/blob/main/docs/migration-0.5.md).

## 0.4.5 · stable

The previous conversation and A2UI APIs. [Open the 0.4.5 guide](/ag-ui-rust/v0.4.5/start/).
These pages are frozen from the [`v0.4.5` tag](https://github.com/KimSoungRyoul/ag-ui-rust/tree/v0.4.5/website/src/content/docs).

## 0.5.0-alpha.1 · superseded

The same 0.5 API, but new Rust 1.85 dependency resolution can fail. Use
alpha.2 for new projects. The [alpha.1 guide](/ag-ui-rust/v0.5.0-alpha.1/start/)
remains available for existing pins.
