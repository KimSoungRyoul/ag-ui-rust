ag-ui-rust API documentation

rustdoc for the SDK's public API, built with all features enabled.

  • ag-ui

    Protocol types, events, and wire encoding, plus the runtimes behind features: serve to host an agent, client and http to consume one, axum to mount one on a router.

  • ag-ui-a2ui

    A2UI (Agent-to-UI) protocol types, semantic validator, and agent-side authoring toolkit.

The rest of the workspace is documented here too. None of it is part of the SDK's public API and none of it is meant to be built against: the task-board and board-watch example programs that the guide walks through, the ag-ui-e2e conformance suite, and the xtask build tool.
