ag-ui-rust API documentation

rustdoc for the SDK's public API, built with all features enabled.

  • ag-ui-core

    Core protocol types, events, and wire encoding for the AG-UI protocol.
  • ag-ui-server

    Server-side runtime for hosting AG-UI agents: agent trait, typestate event emitters, state deltas, and protocol verification. Executor-agnostic.

  • ag-ui-client

    Client-side AG-UI runtime: consume a remote agent's event stream and materialize messages and state.

  • ag-ui-axum

    Axum binding for AG-UI agents: one router extension mounts the canonical POST + SSE endpoint.

  • ag-ui-a2ui

    A2UI (Agent-to-UI) protocol types, semantic validator, and agent-side authoring toolkit.

The rest of the workspace is documented here too. None of it is part of the SDK's public API and none of it is meant to be built against: the task-board and board-watch example programs that the guide walks through, the ag-ui-e2e conformance suite, and the xtask build tool.
